# ludum-dare-template

A template project used primarily for ludum dare game jams.

Contains a few preset up functionality and systems, including:

- Basic generic achievement system (uses user prefs for data so is not cheat safe) - possible improvement, add cheat protection.
- Scalable and generic UI composite state switching system with template setups
- Editor tools including ReadOnlyAttributes for vars in inspector, and struct editing in place for inspector references
- Audio system with mix groups and easy volume integration
- A simple template main menu screen
- Analytics basics and startup logic
- Popups: pause, settings, end game (with high score entry) and high score table
- Local high scores (PlayerPrefs, top 10)
- Developer cheat menu
- Prefab pooling helper

## Jam quick start

### Popups
Drop `Assets/Prefabs/UI/Popups/PopupCanvas.prefab` into any gameplay scene (the scene needs an EventSystem).
- **Pause**: the on-screen pause button (top-right, inside the safe area), Escape or gamepad Start opens the pause popup; Escape/Start also closes the top-most popup. The game auto-pauses when the player switches app or browser tab (not in the editor). Untick `Allow Pause` on `PauseInput` in menu scenes.
- **End game**: `FindAnyObjectByType<EndGamePopup>(FindObjectsInactive.Include).Show(won, score);` (or hold a serialized reference). Shows name entry automatically when the score makes the table.
- **High scores**: open `HighScoresPopup` from a main menu button via `SimplePopup.Open`.
- Popups with `Pauses Game` set freeze `Time.timeScale` while open; it's restored on close or scene load. Use unscaled time for any UI animation.
- Make your own popup by inheriting from `Popup` (or use `SimplePopup`). The prefab is generated by `Tools > Jam Template > Rebuild Popup Canvas Prefab` - restyle it by hand freely, but re-running the tool overwrites it.

### High scores
`HighScoreManager` is static: `IsHighScore(score)`, `SaveScore(name, score)` (returns rank), `GetTopScores()`, `ClearAll()`. Set `HighScoreManager.LowerIsBetter = true` for time trials. Local only - for online leaderboards, look at Unity Gaming Services Leaderboards (the project already uses UGS for analytics).

### Cheat menu
Press **`** or **F1** in the editor or a development build, or on a phone **triple-tap the top-left corner**. Built in: time scale, reload/next scene, clear high scores, clear PlayerPrefs, FPS counter. Add your own from game code:
```csharp
CheatMenu.AddButton("Add 100 score", () => score += 100, this);
CheatMenu.AddToggle("God mode", () => godMode, v => godMode = v, this);
```
To include it in a release build for playtesters, add `ENABLE_CHEATS` to Scripting Define Symbols.

### Object pooling
Use Unity's built-in `UnityEngine.Pool.ObjectPool<T>`, or the `Utils.PrefabPool<T>` wrapper for prefabs:
```csharp
_bullets = new PrefabPool<Bullet>(bulletPrefab, transform);
Bullet b = _bullets.Get(position, rotation);
_bullets.Release(b);
```
Reset per-use state in `OnEnable`. Only pool things that are spawned often (bullets, particles, pickups) - for most jam games `Instantiate`/`Destroy` is fine.

### Mobile web
Every game should be playable on a phone browser:
- Popup buttons are sized for thumbs (110px at 1080p reference). Keep your own buttons at least that size.
- Wrap HUD elements in an object with Unity's **Safe Area** component (Add Component > UI (Canvas) > Safe Area, tick all Edges) so they avoid notches and rounded corners. Don't put it on the root Canvas or on an object driven by a layout group.
- `UnityHelper.IsMobile` is compile-time (native Android/iOS builds only). Use `UnityHelper.IsMobileDevice` to detect phones running the WebGL build, e.g. to show on-screen controls.
- Don't rely on hover, right-click or keyboard-only input. For on-screen sticks/buttons use the Input System's `OnScreenStick` / `OnScreenButton` components.
- Browsers block audio until the first tap, so start music from a menu button rather than on load.
- Test on a real phone early: upload a build to a private itch.io page and open it on your phone.

### Rendering (URP 2D)
The template uses the Universal Render Pipeline with the 2D Renderer (`Assets/URPDefaultResources`, one URP asset per quality level, all sharing `Default_2D_Renderer`).
- New sprites use the lit sprite material, so 2D lights (Light 2D) work out of the box. Add a Global Light 2D to a scene to control overall brightness.
- 3D objects get no real lighting with the 2D Renderer. For a 3D jam, create a URP asset with the Universal Renderer instead (Create > Rendering > URP Asset (with Universal Renderer)) and assign it in Project Settings > Graphics and Quality.
- WebGL uses the "High" quality level by default; drop it to Medium in Project Settings > Quality if mobile browsers struggle.

### TextMesh Pro
TMP Essential Resources live in `Assets/TextMesh Pro` - keep them, the template UI depends on the LiberationSans SDF font.

## Deploying Infrastructure
Sign up for [Google Cloud](https://cloud.google.com/free)

As per https://firebase.google.com/docs/projects/terraform/get-started:
1. Install [Terraform](https://learn.hashicorp.com/tutorials/terraform/install-cli?in=terraform/gcp-get-started)
2. Install [Google Cloud CLI](https://cloud.google.com/sdk/docs/install-sdk)
3. Login with `gcloud auth application-default login`
4. Edit [Infrastructure/vars.tf](./Infrastructure/vars.tf) and set the values you need
    - It's important to set `unrelated_gcp_project_to_verify_billing`. When you signed up for Google Cloud it should have created a project, you can use that ID
5. Run `terraform -chdir=Infrastructure init`
6. Run `terraform -chdir=Infrastructure apply -auto-approve`
7. View the infrastructure at https://console.firebase.google.com/ or https://console.cloud.google.com/welcome

### Configuring Firebase with Unity
As per https://firebase.google.com/docs/unity/setup#add-config-file:
1. Open the [Firebase console](https://console.firebase.google.com/project/) and select the recently created project
2. In the left menu, next to Project Overview click the Gear and select Project Settings
3. On the General tab, scroll down to "Your apps"
4. Click the Android app and download the `google-services.json` file
5. Click the iOS app and download the `GoogleService-info.plist` file
6. Copy these files into the [Assets](./Assets/) folder
7. Go to https://developers.google.com/unity/packages#firebase and download the following packages:
    - [Cloud Firestore](https://developers.google.com/unity/packages#cloud_firestore)
    - [Firebase Authentication](https://developers.google.com/unity/packages#firebase_authentication)
8. In your open Unity project, navigate to Assets | Import Package | Custom Package
9. In the Import Unity Package window, click Import

### Troubleshooting
If you encounter a 403 saying that the Firebase Management API or another permission has not been enabled, wait a little while and run `terraform apply` again.

## Unity Analytics
In order to use the Unity Analytics for this project, you must follow the steps:
1. Setup a Unity Project in https://dashboard.unity3d.com/gaming
2. Setup Analytics inside this project by selecting 'Start Using Analytics'
3. Follow the steps given to link the correct project ID and Organisation from the UGS project, into the project settings of Unity
4. Ensure that the first screen you want analytics to begin from contains a game object with the script UnityAnalytics.cs attached before calling any other analytics related code
Documentation: https://docs.unity.com/analytics/manual/UnityAnalytics
Learning tools: https://learn.unity.com/project/unity-analytics

### Debug mode in editor
Note that you can enable the scripting debug mode for analytics by doing:

1. In the Unity Editor, go to Edit > Project Settings > Player Settings > Player.
2. Locate the Script Compilation section and select Scripting Define Symbols.
3. Add the keyword “UNITY_ANALYTICS_EVENT_LOGS”.
4. Select Apply.
